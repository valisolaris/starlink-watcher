# Starlink 目視可能性チェッカー 仕様書

状態: 凍結済み(2026-08-10)
最終更新: 2026-08-10(ユーザー承認により凍結 / 決定 D-001〜D-013・未決事項ゼロ)
※ 凍結後の仕様変更はユーザー承認必須。変更時は decisions.md に追記し本書を更新する。

## 1. 目的

Starlink 衛星の打ち上げ(衛星群)情報をもとに、自宅や現在地から衛星が目視できる
チャンス(日時・方角・見え方)を調べられる Web アプリケーションを提供する。
「今夜、外に出れば見えるのか?」に短時間で答えられることを価値の中心とする。

## 2. スコープ(確定)

### スコープ内(v1)
- 観測地点の指定: 現在地ボタン+地名検索+緯度経度手入力、localStorage 保存(D-005)
- 5日分の可視パス予報リスト: 日時・方角・最大仰角・明るさ3段階の目安(D-006, D-012)
- 各パスの方位図(極座標の空チャート。トレインは弧上のドット列)(D-006, D-009)
- 打ち上げ直後トレインの検出と優先表示(TLE の OBJECT_ID+低高度推定)(D-003, D-011)
- 可視判定(地平線上/太陽照射/観測地が薄明〜夜)のブラウザ内計算(D-004)
- 案A「Mission Control」デザイン(減光トグル・非公式フッター含む)(D-001, D-009)
- GitHub Actions 日次スナップショット+古い場合のみ CelesTrak 直 fetch(D-010)、
  Vercel で配信(D-013)

### スコープ外(v2 候補)
- 天気(雲量)の考慮(D-007)
- 可視チャンスの事前通知(D-007。実装時はアーキテクチャ再検討が必要)
- 打ち上げ予定の表示(Launch Library 2 等の外部 API)(D-011)
- 英語対応(D-008。UI 文字列の定数分離のみ v1 で行う)

### スコープ外(予定なし)
- Starlink 以外の衛星(ISS 等)の予報
- 天体望遠鏡向けの高精度追尾情報
- ネイティブモバイルアプリ(Web アプリとして提供)

## 3. 前提

- 目視可否は次の3条件の同時成立で決まる: (1) 衛星が観測地の地平線上にある、
  (2) 衛星が太陽光に照らされている、(3) 観測地が十分に暗い(薄明〜夜間)。
- 運用軌道(高度約550km)の Starlink は減光対策により暗く(概ね5等前後)、
  肉眼での視認は困難な場合が多い。肉眼目視の主対象は打ち上げ後数日〜数週間の
  低高度「トレイン」であり、この扱いが本アプリの価値を左右する。
- 軌道データは TLE/GP 形式で CelesTrak 等から無償取得できる。軌道伝播(SGP4)は
  satellite.js 等によりブラウザ内(クライアントサイド)でも計算可能。
- 実測済み(2026-08-10、進行役が curl で確認): CelesTrak GP API(GROUP=starlink,
  FORMAT=json)は `Access-Control-Allow-Origin: *` 付きでブラウザ直 fetch 可。
  レスポンスは約4.36MB・約10,913衛星。各レコードに OBJECT_ID(COSPAR 識別子、
  例 "2019-074B")が含まれ、打ち上げ単位のグループ化に使える。
- 既存類似サービスとして findstarlink.com、heavens-above.com、
  James Darpinian「See a Satellite Tonight」がある(参考・差別化の調査対象)。
- プロジェクトはゼロベース。既存コード・既存ドキュメントは無し。git 未初期化
  (実装フェーズ開始時に init する想定)。
- 開発環境は Windows 11。Python を使う場合は uv 経由で実行する。

### 決定済み方針(Round 1〜2 / 詳細は decisions.md)

- 対象ユーザー: 自分用だが公開可能な作りに(D-002)
- コア体験: 打ち上げ直後トレインの可視チャンス優先+通常通過予報も表示(D-003)
- アーキテクチャ: 完全静的サイト+ブラウザ内 SGP4 計算(satellite.js 想定)(D-004)
- デザイン: SpaceX 風 DESIGN.md の部分採用(トーンのみ翻案、公式誤認を避ける)(D-001)
- 観測地点: 現在地ボタン+地名検索・緯度経度手入力の併用、localStorage 保存(D-005)
- 予報: 5日分の可視パスリスト(日時・方角・最大仰角・明るさ目安)+各パスの方位図(D-006)
- 天気・通知: v2 送り。初期は軌道条件のみで可視判定(D-007)
- 言語・デバイス: 日本語のみ・モバイルファースト(D-008)
- デザイン確定: 案A「Mission Control」のトークンで確定(D-009、詳細は design-brief.md)
- 軌道データ: Actions 日次スナップショット同梱+古い場合のみ CelesTrak 直 fetch(D-010)
- トレイン検出: TLE のみ(OBJECT_ID グループ化+低高度推定、追加 API なし)(D-011)
- 明るさ表示: 3段階の目安(数値等級は出さない)(D-012)
- ホスティング: Vercel(Actions が commit → Git 連携で自動デプロイ)(D-013)
